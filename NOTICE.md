This project began as a fork of DeepSeek GUI by XingYu-Zhong and contributors. It keeps the Kun local agent runtime architecture as its foundation and extends the product direction toward Codex-style desktop workflows, multi-provider model routing including OpenRouter-compatible models, Skills, MCP tools, CLI integration, browser and computer-control workflows, Arabic UI support, and controlled subagent workflows.
